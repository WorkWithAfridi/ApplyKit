GET READY

Start with the essentials.

  1. Save your reusable details.Start with your name, email, phone, and links. Every field is optional; blank values are skipped.
  2. Keep your CV ready.Add your PDF in Links & resume. JSON backups contain profile details, not the PDF itself.
  3. Review before you apply.Check matched fields and tailor company-specific answers. Use popup search to copy and paste anything that needs a manual touch.

OPTIONAL SHORTCUT

Turn your CV into a profile.

  1. Export a starting point.Save any edits, then use Export JSON. Starting fresh? Download the blank template below.
  2. Attach your JSON and CV to ChatGPT.Use the prompt below to ask for an updated import file that preserves existing details and adds only facts supported by your CV.
  3. Review the generated JSON.Check contact details, dates, qualifications, and links. Keep your original backup so you can restore it.
  4. Import the updated file.Choose Import JSON and confirm. Import replaces profile fields, so the generated file must retain anything you want to keep.

Using ChatGPT is optional. You choose which files to share with it; ApplyKit does not upload your profile or CV automatically.
